## 特性路线图

```
v0.7.x ───────────────────→ v0.8 ───────────────────→ v0.9 ───────────────────→ v1.0 (当前) ──────────────→ v1.x
  │                           │                         │                         │                        │
  ├─ DAG 引擎                 ├─ UEBA 行为分析 ✅       ├─ 自定义节点 ✅           ├─ 生产 Compose 加固 ✅   ├─ v1.1: SSO (SAML/OIDC)
  ├─ 触发器                   ├─ Playbook 市场 ✅       ├─ 安全加固 (2FA) ✅       ├─ alert-worker 流式消费 ✅├─ v1.2: K8s 多实例/多租户
  ├─ 人工审批                 ├─ 容器化执行 ✅          ├─ PostgreSQL 生产化 ✅    ├─ 4 核用例 E2E CI ✅     └─ v1.3: XDR 扩展
  └─ AI 告警分析              └─ 多源情报集成           └─ E2E 测试准备 ✅         └─ 55% 覆盖率门禁 ✅
```

## 长期规划 (v1.x)

- **v1.1**: 企业级 SSO 单点登录 (SAML 2.0 / OIDC 协议集成)、高级会话审计
- **v1.2**: Kubernetes 云原生分布式部署方案、多租户完全数据隔离
- **v1.3+**: SOAR 增强、跨平台 XDR 扩展、自动化攻防协同研判
