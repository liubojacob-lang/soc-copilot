# 用户手册（SOC 分析师）

面向日常使用系统的安全分析师。登录后按左侧导航使用各模块。

## 登录与账号
- 首次使用管理员分配的账号登录（`/login`）。若系统要求修改密码，会自动跳转到改密页——设置新密码后用新密码重新登录。
- 右上角可切换中文/英文与亮/暗主题。

## 告警（Alerts）
- 列表支持搜索、严重度/状态筛选、批量更新状态与指派。
- 进入详情可查看生命周期（升级/处置/解决）、添加备注、关联案例。
- 「导入」支持粘贴 CEF / Syslog / JSON / CSV 文本，可先「预览」再入库；同一份内容重复导入会自动去重。

## 案例（Cases）
- 从告警升级或直接新建案例；案例包含时间线、评论、关联告警。
- 状态流转：new → investigating → pending_review → resolved → closed（非法跳转会被拒绝并提示合法选项）。
- 删除需二次确认。

## Playbook（自动化剧本）
- 「定义」页创建/编辑 DAG 剧本（拖拽节点：HTTP 请求、OTX 情报查询、条件、Slack 通知、人工审批等）。
- 执行区分 `dry_run`（演练）与 `apply`（实际执行，需权限）；执行历史保留每次节点输出，可重放（Replay）。
- 需要人工审批的剧本会停在「审批」页；admin/auditor 审批后继续执行。
- 版本管理：draft → published → archived，可回滚任意版本。

## 资产（Assets）
- 资产台账 CRUD + JSON 批量导入；hostname/IP 唯一，冲突返回 409。
- 搜索覆盖 hostname/IP/负责人/业务单元/标签。
- 「云发现」需先配置云厂商凭证；未配置时不要使用（会返回演示数据）。

## 威胁情报与狩猎
- 威胁情报查询 OTX（默认仅外部指标，内网指标被合规过滤）；结果缓存 7 天。
- 威胁狩猎支持假设驱动的狩猎与 Sigma 规则检索；后端不可用时页面会显示错误横幅与重试按钮。

## AI 助手
- 右侧对话支持流式输出；顶部可选模型（Auto 会按问题类型自动路由）。
- 消息输入上限 2 万字符，连续发送受限流（30 次/分钟）。
- LLM 不可用时自动降级为内置规则分析（响应会带降级提示）。

## 报告（Reports）
- 输入告警 ID 生成三类模板（事件工单/日报/复盘），可复制导出。
- 报告由 AI 生成；服务降级时内容会标注「Automated generation failed」。

## 常见问题
- 页面提示 401：会话过期，重新登录即可（前端会自动刷新一次）。
- 操作返回 429：触发了限流，等待一分钟后重试。
- 更多见 `docs/troubleshooting.md`。
