## 预期显示效果

### 面板 1-3: 数字卡片 (stat)

| 面板 | 预期数值 | 颜色阈值 |
|------|---------|---------|
| 告警总数 | ~900-950 | 绿→黄→橙→红 |
| 严重告警 | ~400-420 | 紫→红 |
| 高危告警 | ~350-370 | 黄→橙 |

### 面板 4: 告警趋势 (timeseries)

- **显示**: 3 条彩色柱状图 (严重/高危/中危)
- **X 轴**: 时间 (24 小时)
- **Y 轴**: 告警数量
- **图例**: 显示平均值和最大值

### 面板 5: 攻击类型分布 (piechart)

- **显示**: 饼图 + 右侧表格
- **扇形数量**: 10 个 (top 10 攻击类型)
- **表格列**: 攻击类型 | 数值 | 百分比
- **示例**:
  - ssh_bruteforce: ~25% (红色)
  - port_scan: ~18% (橙色)
  - malware_detected: ~15% (黄色)
  - ...

### 面板 6: 严重级别分布 (donut chart)

- **显示**: 环形图 + 底部表格
- **扇形数量**: 4 个 (critical/high/medium/info)
- **中文映射**:
  - critical → 严重 (红色)
  - high → 高危 (橙色)
  - medium → 中危 (黄色)
  - info → 信息 (蓝色)
- **表格列**: 级别 | 数值 | 百分比

### 面板 7: Top 10 攻击源 IP (table)

- **显示**: 表格 + 热力图背景
- **列**: 来源 IP | 攻击次数
- **热力图**: 绿→黄→橙 (攻击次数越多越红)
- **行数**: 10 行

### 面板 8: 攻击类型排名 (table)

- **显示**: 表格 + 热力图背景
- **列**: 攻击类型 | 告警数量
- **热力图**: 绿→黄→橙→红
- **行数**: 10 行
- **示例**:
  | 攻击类型 | 告警数量 |
  |---------|---------|
  | ssh_bruteforce | 253 |
  | port_scan | 170 |
  | malware_detected | 145 |
  | ... | ... |

### 面板 9: Agent 告警分布 (table)

- **显示**: 表格 + 热力图背景
- **列**: Agent ID | 告警数量
- **热力图**: 绿→黄→橙

## 修复说明

### Piechart 面板修复关键

1. **添加 fieldConfig** - 必须配置颜色模式
2. **使用 instant query** - 返回多个时间序列
3. **配置 legend** - 显示数值和百分比
4. **Panel 6 添加 mappings** - 将英文级别映射为中文

### Table 面板修复关键

1. **使用 instant query** - 返回多行数据
2. **添加 transformations** - 重命名列和隐藏 Time 列
3. **配置 cellOptions** - 启用颜色背景
4. **设置热力图模式** - continuous-GrYlRd
