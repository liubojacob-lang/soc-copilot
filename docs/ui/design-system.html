S SOC Copilot — Design System Phase 2 · 令牌值与 globals.css 一致

Severity 语义色

Critical 红 / High 橙 / Medium 黄 / Low 蓝 / Info 中性灰。组件层只用 severity-* 令牌，明暗切换由 CSS 变量承载，不再写 dark: 变体。

Status 语义色

处置状态。低置信度/未激活用中性色而非危险色 —— 不确定不等于危险。

AI 语义色

靛紫体系，与 severity（红橙）、人工操作（accent 蓝）三方快速可辨。无渐变、无发光。

AI 置信度（缺失时必须显式降级，绝不编造数值）

Typography

7 级字阶，全部带 line-height / letter-spacing 定义。

Spacing

4 基准栅格。禁止页面自造 spacing 数值。

Radius & Elevation

SOC 克制原则：只有 4 级阴影，不出现明显投影堆叠。
