## 🎯 功能 1: 智能事件关联引擎

### 1.1 用户价值

- ✅ 告警聚合：1000+ 原始告警 → 50-100 个关联事件
- ✅ 减少疲劳：分析师工作量减少 80%
- ✅ 提高效率：专注于真实威胁，而非噪音

### 1.2 技术架构

#### 核心组件

```
事件流 → 实体提取 → 时间分组 → 规则匹配 → 相似度计算 → 关联生成
```

#### 数据模型

- `correlation_rules` - 关联规则定义
- `correlated_events` - 关联事件（聚合后的安全事件）
- `event_similarities` - 相似度缓存

#### 算法

1. **实体匹配**: IP、用户、主机名
2. **时间窗口**: 滑动窗口（默认 5 分钟）
3. **相似度计算**: Jaccard 相似度 + 类别匹配 + 严重性邻近度
4. **规则引擎**: 10+ 内置规则（暴力破解、端口扫描、横向移动等）

### 1.3 API 端点

```
POST   /api/correlation/correlate          # 关联事件
GET    /api/correlation/incidents          # 列出关联事件
GET    /api/correlation/incidents/{id}     # 获取事件详情
PUT    /api/correlation/incidents/{id}/status  # 更新状态

# 规则管理
GET    /api/correlation/rules              # 列出规则
POST   /api/correlation/rules              # 创建规则
PUT    /api/correlation/rules/{id}         # 更新规则
DELETE /api/correlation/rules/{id}         # 删除规则
POST   /api/correlation/rules/{id}/toggle  # 启用/禁用
POST   /api/correlation/test               # 测试规则
```

### 1.4 前端组件

- `CorrelationPanel` - 告警详情页显示相关事件
- `IncidentDetailModal` - 关联事件详情和状态更新
- `RuleBuilder` - 可视化规则编辑器（v0.9）

- ✅ 自动分析：一键生成根因报告
- ✅ 深度推理：链式思维，可追溯
- ✅ 节省时间：高级分析师工作减少 70%

### 2.2 技术架构

#### 核心组件

```
告警上下文收集 → 提示词构建 → AI 推理 → 结构化输出 → 人工反馈
```

#### 数据模型

- `root_cause_analyses` - 根因分析结果
- 包含：推理步骤、证据链、验证步骤、修复建议

#### AI 提示词

- **思维链（Chain-of-Thought）**：逐步推理
- **少样本（Few-shot）**：历史案例参考
- **自我验证**：提供验证步骤

### 2.3 API 端点

## 📊 功能 3: 安全效能评分系统

### 3.1 用户价值

- ✅ 量化效能：MTTD、MTTR、假阳性率
- ✅ 趋势分析：周/月/季对比
- ✅ 管理层友好：KPI 仪表盘

### 3.2 指标体系

#### 核心指标

1. **MTTPD** (Mean Time To Prevent) - 平均预防时间
2. **MTTD** (Mean Time To Detect) - 平均检测时间
3. **MTTR** (Mean Time To Respond) - 平均响应时间
4. **假阳性率** - False Positive Rate
5. **Playbook 成功率** - 自动化执行成功率
6. **综合评分** - 0-100（加权计算）

#### 计算逻辑

```
综合评分 = (
    (MTTD 权重 × MTTD 标准化分) +
    (MTTR 权重 × MTTR 标准化分) +
    (假阳性率权重 × 假阳性率标准化分) +
    (自动化率权重 × 自动化率标准化分)
)
```

### 3.3 数据模型

- `security_metrics_snapshots` - 指标快照（每小时）
- `metrics_definitions` - 指标定义和权重

### 3.4 API 端点

```
GET    /api/metrics/score/overview       # 综合评分概览
GET    /api/metrics/score/trends         # 趋势数据
GET    /api/metrics/score/comparison     # 对比历史/行业
POST   /api/metrics/score/export         # 导出报告
```

### 3.5 前端组件

- `ScoreOverviewCard` - 综合评分卡片
- `MetricsTrendChart` - 趋势图
- `KPIComparison` - 对比分析
