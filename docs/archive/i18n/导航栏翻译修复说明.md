# 导航栏翻译修复说明

## 问题描述
导航栏显示英文文本，且文本较长。

## 修复内容

### 1. Navigation.tsx 翻译调用修复
修复了重复命名空间的调用错误：

```typescript
// ❌ 错误（修复前）
const t = useTranslations('navigation');
{ label: t('navigation.home'), path: "/" }

// ✅ 正确（修复后）
const t = useTranslations('navigation');
{ label: t('home'), path: "/" }
```

### 2. 受影响的翻译键
- mainNavItems: home, runs, definitions
- analyticsGroup: analytics, aiCopilot, ueba, threatHunting
- ecosystemGroup: ecosystem, marketplace, cloudNative, dify, alerts, triggers
- adminItems: dashboard, settings, aiModels, apiKeys, audit, users

## 如何查看中文版本

### 方法 1: 访问中文 URL
直接访问：`http://localhost:3003/zh`

### 方法 2: 使用语言切换器
1. 访问任意页面
2. 点击右上角的语言切换器（EN/中）
3. 选择 "中文"
