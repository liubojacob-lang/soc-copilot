## 🚨 常见问题排查

| 问题          | 原因            | 解决方案                       |
| ------------- | --------------- | ------------------------------ |
| AI 对话超时   | AI 服务配置问题 | 检查 `.env` 中的 AI 配置       |
| 数据库错误    | 数据库文件损坏  | 删除 `data/*.db` 重新初始化    |
| 前端 404 错误 | 端口不匹配      | 检查 `next.config.js` 代理配置 |
| 认证失败      | JWT 配置错误    | 检查 `JWT_SECRET` 配置         |
