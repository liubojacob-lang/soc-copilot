# 路线图

## 适用对象

产品经理，开发团队、用户。

## 目标

规划 SOC Copilot 的版本演进方向。

## 版本规划

### v0.7.x - DAG 引擎 (已完成, 2026-01)

| 功能       | 状态 | 说明                   |
| ---------- | ---- | ---------------------- |
| DAG 引擎   | ✅   | 支持节点、边、条件分支 |
| 触发器     | ✅   | Webhook、Cron 触发     |
| 人工审批   | ✅   | 邮件/Slack 审批        |
| OTX 集成   | ✅   | 威胁情报查询           |
| 告警分析器 | ✅   | AI 分析 IOC 提取       |

### v0.8.0 - 增强分析 (已完成, 2026-02 ~ 2026-03)

| 功能              | 优先级 | 状态 | 说明                    |
| ----------------- | ------ | ---- | ----------------------- |
| **多源威胁情报**  | P0     | 🔲   | VirusTotal、IBM X-Force |
| **UEBA 行为分析** | P0     | ✅   | 用户实体行为分析        |
| **告警关联**      | P1     | 🔲   | 自动关联相似告警        |
| **Playbook 市场** | P1     | ✅   | 分享/下载 Playbook      |
| **容器化执行**    | P1     | ✅   | Docker 沙箱执行         |

### v0.9.0 - 自动化增强 (当前版本, 2026-04)

| 功能              | 优先级 | 状态 | 说明                         |
| ----------------- | ------ | ---- | ---------------------------- |
| **自定义节点**    | P0     | ✅   | 用户可编写 Python 节点       |
| **Playbook 市场** | P1     | ✅   | DB 持久化 + 审核工作流       |
| **安全加固**      | P1     | ✅   | 安全响应头、CSP、HSTS        |
| **PostgreSQL**    | P0     | ✅   | 已替换 SQLite                |
| **i18n 国际化**   | P1     | ✅   | 中英双语支持                 |
| **E2E 测试**      | P1     | ✅   | Playwright + Vitest 测试覆盖 |

### v1.0.0 - 生产就绪 (Q3 2026)

| 功能         | 优先级 | 说明               |
| ------------ | ------ | ------------------ |
| **高可用**   | P0     | K8s 多实例部署     |
| **SSO 集成** | P1     | SAML/OIDC 单点登录 |
| **多租户**   | P2     | 隔离租户数据       |
| **合规审计** | P1     | 操作日志、审计报告 |
