# 路线图

## 适用对象

产品经理，开发团队、用户。

## 目标

规划 SOC Copilot 的版本演进方向。

## 版本规划

### v0.7.x - 当前版本 (已完成)

| 功能       | 状态 | 说明                   |
| ---------- | ---- | ---------------------- |
| DAG 引擎   | ✅   | 支持节点、边、条件分支 |
| 触发器     | ✅   | Webhook、Cron 触发     |
| 人工审批   | ✅   | 邮件/Slack 审批        |
| OTX 集成   | ✅   | 威胁情报查询           |
| 告警分析器 | ✅   | AI 分析 IOC 提取       |

### v0.8.0 - 增强分析 (Q1 2024)

| 功能              | 优先级 | 说明                    |
| ----------------- | ------ | ----------------------- |
| **多源威胁情报**  | P0     | VirusTotal、IBM X-Force |
| **UEBA 行为分析** | P0     | 用户实体行为分析        |
| **告警关联**      | P1     | 自动关联相似告警        |

### v0.9.0 - 自动化增强 (Q2 2024)

| 功能           | 优先级 | 说明                   |
| -------------- | ------ | ---------------------- |
| **自定义节点** | P0     | 用户可编写 Python 节点 |
| **节点市场**   | P1     | 分享/下载节点          |
| **容器化执行** | P1     | Docker 沙箱执行        |

### v1.0.0 - 生产就绪 (Q3 2024)

| 功能                | 优先级 | 说明               |
| ------------------- | ------ | ------------------ |
| **PostgreSQL 支持** | P0     | 替换 SQLite        |
| **高可用**          | P0     | 多实例部署         |
| **SSO 集成**        | P1     | SAML/OIDC 单点登录 |
| **多租户**          | P2     | 隔离租户数据       |

## 特性路线图

```
v0.7.x ────────────────────────────────────→ v0.8 ──────────────────────────────────→ v0.9 ─────────────────────────────→ v1.0
  │                                              │                                       │                            │
  ├─ DAG 引擎                                    ├─ 多源威胁情报                         ├─ 自定义节点                    ├─ PostgreSQL
  ├─ 触发器                                       ├─ UEBA 行为分析                        ├─ 节点市场                       ├─ 高可用部署
  ├─ 人工审批                                     ├─ 告警关联                             ├─ Docker 沙箱                    ├─ SSO 集成
  └─ AI 告警分析                                  └─ 资产自动发现                         └─ 并行执行                       └─ 审计合规
```

## 长期规划

- **v1.1+**: SOAR 增强、XDR 扩展、自动化研判
- **生态系统**: CLI 工具、Python SDK、API 文档
