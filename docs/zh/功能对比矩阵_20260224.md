## 三、架构模式对比

### 3.1 数据流架构

#### SOC Copilot 数据流
```
外部告警 (手动/API)
    ↓
AI 分析引擎
    ↓
告警存储 (SQLite)
    ↓
Playbook 触发
    ↓
自动化响应
```

**特点**:
- ✅ AI 驱动分析
- ✅ Playbook 自动化
- ❌ 缺少日志采集层
- ❌ 单体架构

#### security-monitoring-system 数据流
```
日志源 (Wazuh Agent/Snort)
    ↓
Wazuh Manager (规则检测)
    ↓
Elasticsearch (存储)
    ↓
Alert Producer (轮询 ES)
    ↓
Redis Streams (优先级队列)
    ↓
Alert Worker (消费者)
    ↓
通知渠道 (Feishu/Slack/Email)
```

**特点**:
- ✅ 完整日志采集链路
- ✅ 规则驱动检测
- ✅ 消息队列解耦
- ✅ 水平扩展
- ❌ 缺少 AI 分析
- ❌ 缺少自动化编排

## 四、集成方案建议

### 4.1 推荐架构: 互补集成

```
┌─────────────────────────────────────────────────────────┐
│           集成方案: Wazuh + SOC Copilot                  │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ┌────────────────┐         ┌────────────────┐          │
│  │  Wazuh Stack   │         │ SOC Copilot    │          │
│  │  (日志层)      │         │ (分析层)       │          │
│  ├────────────────┤         ├────────────────┤          │
│  │ • Wazuh Agent  │───────→ │ • 告警接收 API │          │
│  │ • Wazuh Rules  │  Webhook│ • AI 分析引擎  │          │
│  │ • Elasticsearch│        │ • Playbook 引擎│          │
│  │ • Kibana       │        │ • 前端 UI      │          │
│  └────────────────┘         └────────────────┘          │
│          │                           │                 │
│          └───────┬───────────────────┘                 │
│                  ↓                                       │
│          ┌──────────────┐                              │
│          │  PostgreSQL  │ (共享数据库)                  │
│          └──────────────┘                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 集成步骤

#### 步骤 1: Wazuh → SOC Copilot 告警推送
- Wazuh 配置 Webhook 输出
- SOC Copilot 接收告警 API
- 告警格式转换 (Wazuh → SOC Copilot Schema)

#### 步骤 2: 联合查询
- SOC Copilot 通过 ES API 查询原始日志
- 前端嵌入 Kibana Iframe
- 统一搜索界面

#### 步骤 3: 联动响应
- SOC Copilot Playbook 触发 Wazuh 主动响应
- Wazuh 隔离主机 → SOC Copilot 记录工单
- 双向状态同步

### 最终建议

**推荐方案**: 集成 Wazuh + SOC Copilot

**理由**:
1. Wazuh 提供成熟的日志采集和规则检测
2. SOC Copilot 提供强大的 AI 分析和自动化编排
3. 两者互补, 形成完整 SIEM + SOAR 平台
4. 避免重复造轮子, 加速产品上市

**集成优先级**:
1. **P0**: Wazuh 告警 → SOC Copilot Webhook
2. **P1**: Elasticsearch 日志查询集成
3. **P2**: Kibana 嵌入 + 联动响应
